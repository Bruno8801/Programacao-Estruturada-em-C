# Programação Estruturada em C 💻

Este repositório reúne exercícios, exemplos práticos e projetos desenvolvidos durante meus estudos em **Programação Estruturada na Linguagem C**.

O conteúdo aborda desde os conceitos fundamentais da linguagem até temas mais avançados, como alocação dinâmica de memória, manipulação de arquivos e desenvolvimento de aplicações utilizando múltiplos arquivos.

---

- Entrada e saída de dados

## 🚀 Como Executar

### Clonar o Repositório

```bash
git clone https://github.com/Bruno8801/Programacao-Estruturada-C.git
```

### Acessar a Pasta

```bash
cd Programacao-Estruturada-em-C
```

### Compilar um Arquivo C

```bash
gcc programa.c -o programa
```

### Executar

```bash
./programa
```
